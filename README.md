# Metro Ride 2D — Train Simulator

A browser-playable 2D metro train simulator with a dark-blue cockpit HUD, animated city/rail scene, speedometer, throttle and brake controls, station route progress, passenger exchange, door interlock, announcements, pause/reset and emergency braking.

## Run locally
Open `index.html` in a modern browser. No build step or dependencies required.

## Controls
- **W** — accelerate
- **S** — apply brake
- **D** — open doors (only when stopped)
- **C** — close doors
- **Space** — emergency brake
- On-screen sliders and buttons are also available.

## GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/ (root)**, then click **Save**.
4. After GitHub finishes deployment, the published URL will appear in the Pages section.

The 0–1000 km/h range and 500 km station distance are arcade-game settings, not real metro operating specifications.
